# Machine Learning

Machine learning is the study of algorithms that improve at a task by learning from data rather than following hand-written rules.

## Core ideas
- A model has parameters that are fit to training data by minimizing a loss function.
- The most common optimizer is [[Gradient Descent]].
- The central risk is [[Overfitting]]: doing well on training data but poorly on new data.

## Model families
- Linear and logistic regression — simple, interpretable baselines.
- [[Neural Networks]] — stacked layers of learned transformations.
- [[Transformers]] — the architecture behind modern language models.

## Representations
Most modern systems turn inputs into vectors; see [[Embeddings]].
