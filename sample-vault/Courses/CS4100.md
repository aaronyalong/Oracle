# CS4100

CS4100 — Artificial Intelligence, Fall 2025. Taught by Professor Lena Rao.

## Topics
Search and planning, probabilistic reasoning, [[Machine Learning]] basics, and neural networks.

## Final project
An image classifier for CIFAR-10 built as a [[Convolutional Neural Networks|CNN]]. It reached 84% test accuracy after adding data augmentation. Training notes are in [[Gradient Descent]].

## Grading
Problem sets 40%, midterm 20%, final project 40%.
